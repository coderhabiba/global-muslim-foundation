Flat directory of standalone `.html` pages (`index.html`, `appeals.html`, `campaign-details.html`, `impact.html`, `about.html`, `volunteer.html`, `zakat-calculator.html`) plus `404.html` and `favicon.svg`. There is no build step: `netlify.toml` sets `publish = "."` so every file is served directly. Each page bundles its own `<style>` block defining a Material-3–inspired design-token system (headline-xl/lg/md/sm, title-lg/md/sm, body-lg/md/sm, label-lg/md/sm) plus a full Tailwind color palette, then loads Tailwind via the CDN script with an inline `tailwind.config` that extends colors, fontSize, and fontFamily. Navigation between pages is plain relative `<a>` links; there is no shared JS or component layer. Routing relies on Netlify's built-in pretty-URL resolution (`/about` → `about.html`) and automatic `404.html` fallback — both `netlify.toml` and `_redirects` explicitly document why no catch-all rule is added. Security headers (X-Frame-Options, X-Content-Type-Options, XSS-Protection, Referrer-Policy, Permissions-Policy) are declared once in `netlify.toml`; asset caching is set for `/assets/*`.
