The root is a single Next.js 16 / React 19 application whose `app/` directory (app_routes) provides the active pages and layout shell, while `components/` holds shared client-side UI. The older hand-authored site lives under `legacy_site/` as a self-contained archive; it is no longer built by this repo but kept for reference. Cross-child wiring happens at the root: `next.config.ts` defines permanent redirects from every legacy `.html` URL to its clean App Router counterpart so bookmarks and external links survive the migration, and `netlify.toml` builds the Next.js app via `@netlify/plugin-nextjs`, carries over the security headers that the legacy static site used, and documents that legacy HTML/_redirects are now handled by the App Router's `not-found.tsx` and the redirect map in `next.config.ts`. There is no runtime dependency between `legacy_site/` and the Next.js app — it is purely archival.
