Built on Next.js App Router with two layout layers: `app/layout.tsx` is the root layout that injects Google fonts (Playfair Display, Plus Jakarta Sans), Material Symbols, global CSS, and shared metadata; `(site)/layout.tsx` is a Route Group layout wrapping every public page in `SiteHeader` + `SiteFooter`, keeping navigation chrome out of individual pages. Static content lives as one-page-per-route under `(site)/` (`about`, `appeals`, `campaign-details`, `impact`, `volunteer`, `zakat-calculator`) plus a home `page.tsx`. A single API route at `app/api/forms/route.ts` exposes a POST endpoint that mirrors the legacy Netlify form contract (parses `form-name` from URLSearchParams) without persisting data — persistence is delegated to the host. `not-found.tsx` provides a custom 404 page reusing `SiteHeader` and `NotFoundPage` components.
